Sistema de Citas Médicas Web

Descripción

Versión web del sistema de la clínica ficticia Salud y Bienestar. Los clientes pueden registrarse, consultar médicos y su disponibilidad, y agendar o cancelar sus citas; los empleados de la clínica administran médicos, especialidades, horarios, clientes y empleados, gestionan las citas y facturan los servicios con el cálculo del IVA.

Mi rol

Proyecto desarrollado en parejas como prueba final del curso TI-141 Programación III del Colegio Universitario de Cartago (II cuatrimestre de 2026). Trabajamos de forma colaborativa en el diseño y el desarrollo del sistema completo.

Arquitectura

  • Frontend: aplicación web en C# con ASP.NET Core MVC (.NET 8).
  • Comunicación: el frontend envía sus peticiones por un socket al backend, en mensajes JSON con acción y datos; el backend responde con un estatus, un mensaje y los datos.
  • Backend: servidor en Python que atiende cada petición en un hilo independiente.
  • Datos: MongoDB para médicos, clientes, empleados, especialidades, datos de la clínica, horarios y usuarios; SQL Server para citas, facturas y detalle de facturación.

Tecnologías utilizadas

  • C#
  • ASP.NET Core MVC (.NET 8)
  • Python (sockets e hilos)
  • MongoDB
  • SQL Server
  • JSON
  • HTML y CSS

Funcionalidades

  • Acceso: registro de usuarios desde la página inicial e inicio de sesión de clientes y de empleados, solo si están activos. Las claves se guardan cifradas con hash.
  • Clientes: actualizar sus datos, consultar médicos por especialidad, ver la disponibilidad semanal, agendar citas, modificarlas o cancelarlas con al menos dos días de anticipación, y ver su historial y su facturación.
  • Empleados: mantenimiento de médicos, especialidades, horarios, datos de la clínica, clientes (activos o inactivos) y otros empleados; registrar, modificar o cancelar citas; y ver el horario semanal de cada especialista con las citas asignadas y las disponibles.
  • Facturación: registro de los servicios recibidos, cálculo del IVA y del total mostrando el detalle antes de pagar, y registro del pago.
  • Validación de datos: revisa tipos, rangos y duplicados en las entradas y avisa al usuario para que pueda corregir.
